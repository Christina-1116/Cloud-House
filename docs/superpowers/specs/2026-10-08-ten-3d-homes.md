# 十间可生活的 3D 云端小屋

用户要求人物与宠物的陪伴式互动成为核心，十个旅居场景都必须拥有实际立体空间。默认进入 3D，地图选房后进入相应的三维世界；参考插画继续作为地图封面与收藏画册。六位住客、九猫两狗、现有生活动作、家具编辑、写信和小游戏都在各房间延续。

十种建筑分别为原居、暖炉木屋、海岸拱廊、玻璃花房、和风茶舍、法式宫室、都市阁楼、北欧小屋、落日藤编、月门山房。暖炉、花房、茶舍、宫室和阁楼使用后侧抬高区域与可以寻路的楼梯，角色、宠物及家具的高度由同一地面函数确定，禁止直接穿过高台边缘。其他小屋采用开放单层空间，建筑、固定装饰与家具布局各有区别。

人物与宠物选择、货币、背包、亲密度和信件全局保留。每间小屋的家具位置与自定义配色独立存档。旧 `cloudhome.v3` 的家具迁移到原居，并保留已有位置与购买记录。切换前同步捕获当前布置，清理动作、小游戏和旧建筑自有 GPU 几何；共享基础材质与几何不重复销毁。快速切换不依赖延迟保存成功。

每间默认提供床、厨房、沙发、书桌、餐椅、茶桌、花槽、宠物窝等生活设施；不同场景还有壁炉、拱窗、绿植、樱树、金饰、城市天际线、藤编与竹林。切换场景不强制更换用户选择的住客或宠物。3D 里提供换房、聊天、陪宠物、喝茶、故事与房间小游戏入口。

运行保持独立 `index.html`，无 CDN 或 API 依赖，支持直接双击及 HTTP。自动化验证每间场景的真实 3D 网格、相机角度、核心动作到达、楼梯高度、布置往返保存、旧存档、快速切换、照片、移动布局及资源释放。实体手机与比赛平台另行实机确认。
