# 验证记录

## 通过的检查

- `npm run build`：构建产物生成，合并模块通过 `node --check` 语法校验。
- `npm test`：7 项状态测试通过。涵盖全部房间可达、探索奖励幂等、三条件邮票、独立进度、坏数据容错、非法动作、晚会门槛与奖励幂等。
- `npm run test:browser`：21 项 Chromium 浏览器检查通过。实际完成 10 个房间，游玩 4 类仪式小游戏；记录到 0 个运行时错误、0 个缺失资产响应、0 个外部网络请求。
- HTTP 本机预览与 `file:///…/index.html` 直接打开各通过完整 21 项浏览器回归。
- `npm run test:offline`：将首页单独复制到中文和空格路径的空文件夹，并阻止其他资源加载；Chromium 和 WebKit 均通过初始化、十场景地图、探索、真实 PNG 下载、刷新存档和 3D 小屋交互。无需 `public/` 或本机服务。
- 实际下载 PNG 明信片；实际把旅居奖励云朵灯取出并放进 3D 小屋。
- 桌面 1440×960 与手机 390×844 截图检查；场景容器与画面比例对齐，手机无横向溢出，地图十张缩略图全部完成加载。
- 旧 v3 存档恢复测试：保留住客、星星币和已有核心家具，不需要已有 `journey` 字段。
- `git diff --check`：通过。

浏览器脚本使用 Playwright，Chromium 使用软件 WebGL，以便在无物理显示器的自动化环境中启动原有 3D 渲染。报告与截图生成到本地 `qa/`，不作为产品运行依赖。

## 复核中发现并解决

- 泡茶快捷键会截获关闭按钮的 Enter：现在在按钮上保留原生键盘操作。
- 探索奖励重绘导致对话框丢失返回焦点：按热点身份恢复到重绘后的按钮。
- 场景被最大高度压缩时，容器比例与图像比例不同：调整可用高度，保持完整画幅与热点对齐。
- 地图懒加载时立即解码会出现空白缩略图：地图和旅居册的小缩略图使用主动加载，浏览器测试等待十张图全部加载。
- 原有 `refreshLamps()` 的 `applyLights()` 被注释吞掉：恢复执行。
- 原有家具拖动后在退出摆放前不保存：成功移动后更新寻路、灯光并保存。
- 双击首页时 `file://` 模块导入被 CORS 拦截：现在将 Three.js、Tween.js 与游戏代码打包成内联普通脚本，全部图片与许可证一起嵌入首页。
- 试玩链接指向临时本机服务，服务结束后无法访问：恢复独立后台运行的本机服务，并交付可以直接打开的独立首页，日常离线试玩无需服务。

## 实际验证范围

完整游戏流程验证于 Chromium；WebKit 另验证直接打开的离线关键流程。WebKit 引擎测试不能替代所有 Safari 设备的实际测试。手机测试是响应式视口与触控布局检查，尚未在实体 iPhone/Android、Safari 应用、Firefox 或比赛现场设备上确认。没有运行比赛平台专项测试，因为比赛名称、规则和提交平台尚未提供。需在最终参赛设备上做一轮真实试玩。

新增十个场景采用用户素材做互动绘本，保留原 3D 小屋独立玩法。九張家具素材板用于风格收藏图鉴，奖励使用原有真实 3D 家具，未声称从图片生成了对应模型。
