# 云端小屋 · 云上旅居

目的：丰富原有单一 3D 小屋，用用户提供的场景和住客素材做出可以直接参赛演示的浏览器游戏扩展。比赛规则未提供，按桌面与移动浏览器、中文、无需账号、可离线游玩设计。

保留原有 3D 小屋、家具编辑、住客作息、小游戏和 cloudhome.v3 存档。在此基础上新增绘本式旅居入口。10 个房间全部可到访，避免用等待或付费阻碍演示。

每个房间有三处可寻找的小物、一个短小游戏、一段有两种回应的住客故事。探索、仪式和故事分别盖印，三枚印章组成房间邮票。首次奖励仅发放一次，重玩可改善最佳成绩。完成五张邮票可参加云端晚会，完成十张可收齐旅居册。

小游戏采用四种机制：三段火候/泡茶计时、翻牌配对、声音序列记忆、连星寻路。主题内容、节奏、配色与发现小物随房间改变。失败可即刻重试，没有体力限制。

界面：纸张色、森林绿、细线装饰、衬线中文标题；场景以完整画幅展示，热点按画幅归一化定位。桌面旁栏与场景并列，手机切为紧凑上下布局。提供键盘与点击操作、减弱动态效果、音效开关、静音模式、场景加载失败提示。

素材：所有场景、角色与家具图来自用户 zip；保留原文件名清单，构建时转换为 WebP 并控制尺寸。角色全身图用于档案，家具图用作风格收藏图鉴，不冒充可编辑 3D 模型。运行依赖本地化，构建产物可使用本地 HTTP 服务或静态部署。

验证：奖励幂等性、独立场景进度、旧存档迁移、坏数据容错、结局门槛；浏览器验证首次进入、三类任务、旅居完成、重玩与刷新恢复、3D 回退、手机布局、无浏览器运行错误。交付完整源码、可玩构建、素材清单、测试记录与参赛演示说明。
