# 参赛演示建议

比赛主题、平台、截止日和素材授权要求尚未提供。以下为当前版本的可执行演示路线，最终提交格式应按比赛规则调整。

## 作品概念

一封空白的明信片，带玩家拜访十间云上小屋。每一站留住三件事：发现一件日常物品、认真做好一件小事、倾听一个朋友。旅行获得的家具可以带回原有 3D 小屋，探索与安家形成完整循环。

## 3 分钟演示

1. 从“云端原居”开始，点击三处微光。展示图中物件如何展开为具体故事，以及每个发现都记录进度。
2. 玩“给初见泡一杯茶”：指针走到绿色区间时按下，共三步。显示分数与仪式印章。
3. 听阿屿的故事，选一个回应，展示旅居邮票和真实家具奖励。
4. 打开云海地图，切到“海盐假日”“森屿花房”“星幕阁楼”。分别展示收藏配对、风铃序列和星座连接，说明房间的故事和玩法有所差异。
5. 保存一张 PNG 明信片。回到 3D 小屋，在“商店 → 背包”取出云朵灯，拖动家具并让住客走过去。

五张邮票后的云端晚会是故事结局，十张邮票是完整收藏目标。不要用测试接口直接跳到结局作为正常游玩录像；演示可剪辑真实进度。

## 打包与现场准备

- 静态运行包包含根目录 `index.html`、完整 `public/` 与 README。源码、测试与说明另行保留。
- 使用本地 HTTP 服务或静态网站部署，不能只提交 HTML 后丢掉 `public/`。
- 所有玩法可在断开互联网后继续运行，但本地 HTTP 服务仍需运行；3D 启动需要浏览器支持 WebGL。
- 提前用比赛现场的实际设备验证 3D 加载、声音、触控、照片下载与字体。现有自动化测试使用 Chromium；其他浏览器仍需实际设备试玩。
- 素材原包为 79.3 MiB，当前 WebP 共 6.57 MiB，包含场景、角色和家具图。提供素材来源和比赛需要的使用授权资料。
- 不声明“完全无缺陷”或“所有浏览器已经验证”。已确认的构建、状态测试、浏览器用例记录在 `docs/verification.md`。
